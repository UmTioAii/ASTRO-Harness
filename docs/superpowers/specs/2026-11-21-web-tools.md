# S7 — Web tools

> Objective: add cached, deduplicated, citable web results with audited backend fallback.

- Status: draft (alpha.5, phase P5.5)
- Date: 2026-11-21
- Depends on: S6 (output contract)
- Owner files: `src/tools/web-search.ts`, `src/tools/web-fetch.ts`, `docs/web-tools.md`

## 1. Current state, verified

`web-search.ts` (297 lines): four backends (`exa`, `brave`, `google`, `custom`), three
attempts with cancellable backoff, 5 results by default capped at 10, 500-character snippets,
results untrusted and redacted, `web.search` audit with the query redacted.
`web-fetch.ts` (258 lines): 50k characters by default, three redirects, private URL guard.
Owner doc: `docs/web-tools.md`.

## 2. Gaps this spec closes

| Gap | Consequence today |
|---|---|
| no dedupe or ranking by canonical URL | the model receives three links to the same page without knowing |
| no stable per-result id | citations are URLs recalled from memory; `[n]` does not exist |
| no cache per (backend, query) | repeating a search costs again inside the same turn |
| one global backend | a backend outage fails the tool; no declared fallback |
| no `depth` (search vs search-and-read) | the model searches and answers without opening anything |
| audit without per-backend cost | "how much did I spend on search" cannot be answered |

## 3. Contract

**Dedupe and ranking.** Canonicalize the URL (scheme, host case, trailing slash, tracking
parameters), collapse duplicates keeping the best snippet, and preserve the backend's order
within the group.

**Citations.** Each result gets a stable `[n]`, and the tool description instructs the model
to cite by id. A citation must map to a result actually returned in this run.

**Cache.** Keyed by (backend, canonical query, options), bounded, in-memory for the run. An
identical query inside the same run is served from cache and marked as cached in the audit.

**Fallback.** A declared chain of backends: on transport failure the next one is tried, with
the reason recorded. An absent backend credential skips that backend rather than failing the
whole tool.

**Depth.** `search` returns results; `search_and_read` also fetches the top N pages through
`web_fetch`, under the same byte ceiling and the same untrusted-content rules. No JavaScript
execution, no browser.

**Audit.** Per-backend calls, cache hits, result count and failure reason. No credential, no
full URL with query tokens in the log.

## 4. Acceptance

- [ ] An identical query inside a run is served from cache.
- [ ] Ten results carry a stable `[n]` and duplicates by canonical URL are collapsed.
- [ ] A backend outage moves to the next declared backend and the reason is audited.
- [ ] `search_and_read` respects the byte ceiling and marks all content as untrusted.
- [ ] No credential appears in any log or result.
- [ ] Each backend is covered by a test with a mocked `fetch`.

## 5. Out of scope

Crawling, browsers, JavaScript rendering, scheduled monitoring, paid re-ranking services.
